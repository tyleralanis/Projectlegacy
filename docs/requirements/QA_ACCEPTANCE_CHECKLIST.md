# QA Acceptance Checklist v2.0

## Offline/local-first
- [ ] Airplane-mode new life works.
- [ ] Airplane-mode birth-to-death-to-heir works.
- [ ] Business, property, generated markets, politics, legal/crime, relationships, health, and dynasty all operate offline.
- [ ] No screen blocks on reachability or a failed endpoint.
- [ ] Save export/import works offline.
- [ ] No AI request leaves the device.

## Simulation
- [ ] 10,000 seeded lives without uncaught exception.
- [ ] 1,000 five-generation dynasty runs.
- [ ] 100 200-year stress worlds.
- [ ] 1Y vs 52x1W parity under equivalent intervention policy.
- [ ] No NaN/Infinity/negative impossible ownership/orphan references.
- [ ] No guaranteed extreme-wealth investment/business/property path across regression seeds.

## Systems
- [ ] Elite education affects access/network but does not guarantee competence/success.
- [ ] Bought/manipulated credential can diverge from competence and create later exposure.
- [ ] Business advertising can help, saturate, or overwhelm capacity.
- [ ] Investor capital can dilute founder/control.
- [ ] Rentals can be profitable or loss-making and scale into delegated portfolios.
- [ ] Net worth and cash/liquidity are distinct.
- [ ] Insider misconduct is optional, abstract, and can create delayed exposure.
- [ ] Political office has eligibility, campaigns, opposition, institutional limits, and governing after victory.
- [ ] Abstract coup/power-seizure path never exposes tactical instructions.
- [ ] Death preserves world and succession facts.

## Intent
- [ ] Common actions never require typing.
- [ ] `Other...` resolves supported actions locally.
- [ ] Ambiguous input asks one concise clarification/confirmation rather than guessing.
- [ ] Destructive/irreversible proposed actions require confirmation when confidence is not high.
- [ ] Impossible requests return reasons/prerequisites rather than magic success.

## iOS/release
- [ ] Clean EAS production build from fresh checkout.
- [ ] Real-device TestFlight install.
- [ ] StoreKit purchase/restore if included.
- [ ] Previously owned content available offline after prior verification.
- [ ] Dynamic Type, VoiceOver, Reduced Motion, haptics off.
- [ ] Privacy/age-rating answers match actual local-only architecture and content.
