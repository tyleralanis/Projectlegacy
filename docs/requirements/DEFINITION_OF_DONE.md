# Definition of Done v2.0

A build is not final until:

- [ ] The authoritative save/world is local and versioned.
- [ ] No developer server is required for gameplay or AI.
- [ ] A complete life and dynasty are playable in airplane mode.
- [ ] Weekly simulation and all five time controls are stable.
- [ ] Major systems are interconnected, not isolated menus.
- [ ] Common actions use fast UI; optional `Other...` supports unusual intents.
- [ ] The engine validates every action; AI/interpreter never writes state.
- [ ] Education, career, business, property, markets, relationships, politics/government, organizations, crime/legal, health/reputation, inheritance/dynasty have launch-ready loops.
- [ ] Wealth creates additional strategic layers instead of ending the game.
- [ ] 10,000-life, dynasty, and long-world stress tests pass.
- [ ] Save recovery/export/import and schema migration tests pass.
- [ ] No severity-1 bug, save corruption, or known infinite-money exploit.
- [ ] GitHub source, EAS config, tests, schemas, content guide, TestFlight build, and App Store Connect archive are delivered.
