# UI / Visual Implementation Spec v2.0

## Overall feel
Premium editorial life journal plus modern finance/product dashboard. Calm, mature, tactile, original, and fast. Complex simulation; simple surface.

## Light tokens
Canvas `#F6F4EF`; Surface `#FFFFFF`; Secondary `#EEF2F1`; Text `#182126`; Secondary text `#667279`; Border `#DDE3E4`; Accent `#1D5C63`; Legacy `#C18C37`; Success `#2F6B4F`; Danger `#A33A3A`.

## Dark tokens
Canvas `#0F1417`; Surface `#171E22`; Secondary `#20292E`; Text `#F4F6F6`; Secondary text `#A5B0B5`; Border `#2B373D`; Accent `#6AA8AE`; Legacy `#D5AA62`; Success `#70A988`; Danger `#D16A6A`.

## Layout
20pt screen horizontal padding; 16pt card padding; 14pt card radius; 44pt minimum targets; five bottom destinations maximum; Dynamic Type without clipping.

## Life screen
Identity/date/city -> compact Cash/Net Worth/Health/Mood -> active thread -> life feed -> three focus slots -> fixed 1W/1M/3M/6M/1Y tray -> bottom nav.

## Object pages
Show the 3-7 highest-frequency actions for the object. Put secondary known actions under `More`. Put `Other...` last. The presence of free text must not make the screen look like a chat application.

## Major event
Date/category, concise facts, relevant participants/stakes, 2-5 common choices, More context, optional Other. Risky/destructive styling can be semantic but not sensational.

## Dashboards
Use qualitative health/status and compact KPIs first. Detailed accounting/market/organization tables are disclosures or secondary tabs, not the home screen.
