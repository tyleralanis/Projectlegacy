Support

For bugs, questions, feedback, or feature requests, open a support request in the Project Legacy repository.

Email Project Legacy support

Open a Project Legacy support request

Do not attach a private save file to a public issue. Email support first if a report involves private save data.

Save recovery

Project Legacy keeps rolling local recovery checkpoints. If a save cannot load, leave the app installed and report what happened before attempting to delete or import a world.

Save portability

Use More → Export save to create a checksummed .legacy file. Use More → Import save to restore a package you previously exported.

Offline play

Gameplay does not require a network connection. The enhanced language tier depends on compatible Apple Intelligence hardware and software, but the deterministic local tier remains available.
